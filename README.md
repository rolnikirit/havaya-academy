# אתר הוויה — תיקיית פרויקט מרכזית

כל מה שקשור לאתר החדש של הוויה נמצא כאן, במקום אחד.

## מבנה התיקייה

```
אתר_הוויה/
├── index.html              ← דף הבית (האתר בפועל)
├── practitioners.html       ← עמוד "מטפלים מוסמכים" (האתר בפועל)
├── course-*.html            ← 5 עמודי קורס נפרדים (מיכאל, הילינג, רייקי 1+2, רייקי 3, שנתי) — כל קורס בכרטיס בדף הבית מקשר לעמוד שלו
├── havaya_logo.webp         ← לוגו מלא (עם טקסט), בשימוש בשני העמודים. הוחלף מ-PNG של 2.9MB לגרסת webp זהה של 18KB בלבד — אותה תמונה, בלי הבזבוז.
├── havaya_symbol_only.png   ← הסמל בלבד (הפרח הזהב, בלי טקסט, רקע שקוף) — לא בשימוש עדיין, מתאים ל-favicon/אייקון קטן
├── irit_final.jpg           ← תמונת פורטרט של אירית (בשימוש בדף הבית)
├── Irit_clean.jpg           ← תמונה שנייה, שונה, של אירית (חוץ, טבעי) — לא בשימוש עדיין, זמינה לשימוש עתידי
└── מסמכי-תכנון/
    ├── תכנון_מלא_האתר.html       ← מסמך התכנון הפנימי המלא (sitemap, תרשימי זרימה)
    ├── הצעה_לאישור_אירית.html    ← גרסה מקוצרת וידידותית, מיועדת לשיתוף עם אירית
    ├── תבנית_תעודת_מטפל.html    ← תבנית עריכה לתעודת "מטפל/ת"
    └── מחקר_ותובנות.md           ← כל המחקר וההחלטות (ביקורת אתר ישן, השוואת סליקה, Wix מול קוד עצמאי, נגישות וכו')
```

## איך לפתוח

כל קובצי ה-HTML נפתחים ישירות בדפדפן (לחיצה כפולה, או גרירה לדפדפן). אין צורך בשרת או התקנה.

## מה עדיין חסר (לפרטים המלאים ראו מסמכי-תכנון/מחקר_ותובנות.md, סעיף 8)

רשימת קורסים מלאה · מחירים · עדויות נוספות · הכשרות אירית · קישורי פייסבוק/אינסטגרם · תשובת uPay לגבי חיבור לאתר עצמאי · סטטוס עסקי לנגישות

## איך לעדכן את האתר בעתיד

עורכים את קבצי ה-HTML ישירות, ואז מעלים ל-Netlify (drag & drop ל-app.netlify.com/drop, לאותו אתר קיים כדי לעדכן ולא ליצור כתובת חדשה). ראו הרחבה במחקר_ותובנות.md.
